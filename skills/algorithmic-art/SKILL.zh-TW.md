演算哲學是一種計算美學運動，並透過程式碼加以表達。輸出 .md 檔（哲學宣言）、.html 檔（互動瀏覽器）與 .js 檔（生成演算法）。

此流程分兩個步驟：
1. 建立演算哲學（.md 檔）
2. 以 p5.js 生成藝術加以表達（.html + .js 檔）

請先完成以下任務：

## 演算哲學建立

首先，建立一套**演算哲學**（不是靜態圖像或樣板），並透過以下面向加以詮釋：
- 計算過程、湧現行為、數學之美
- 種子隨機性、噪音場、有機系統
- 粒子、流動、場域、力場
- 參數變化與受控混沌

### 核心認知

- 所接收到的：使用者給的某些細微輸入或指示，可作為參考基礎；但不應限制創作自由。
- 所要創造的：一套演算哲學／生成式美學運動。
- 接下來發生的：同一版本接收到哲學宣言後，會**以程式碼加以表達**——建立 90% 演算生成、10% 核心參數的 p5.js 草圖。

建議的思考方式：
- 為一個生成藝術運動撰寫宣言
- 下一個階段是撰寫讓它活起來的演算法

哲學宣言必須強調：演算表達、湧現行為、計算之美、種子變化。

### 如何生成演算哲學

**為運動命名**（1-2 個詞）：「Organic Turbulence」（有機湍流）／「Quantum Harmonics」（量子諧波）／「Emergent Stillness」（湧現靜止）

**闡述哲學**（4-6 段，精煉但完整）：

為了捕捉**演算的本質**，請表達此哲學如何透過以下方式展現：
- 計算過程與數學關係？
- 噪音函式與隨機性模式？
- 粒子行為與場域動態？
- 時間演化與系統狀態？
- 參數變化與湧現複雜性？

**關鍵指引：**
- **避免重複**：每個演算面向只提一次。除非能增添新的深度，否則避免反覆提及噪音理論、粒子動態或數學原理等概念。
- **反覆強調工藝精神**：哲學宣言**必須**多次強調，最終演算法應令人感覺是花了無數時間打磨、精心細作的成果，出自該領域頂尖人士之手。這個框架至關重要——請反覆使用「精心雕琢的演算法」、「深厚計算專業的產物」、「嘔心瀝血的最佳化」、「大師級實作」等詞句。
- **留下創作空間**：對演算方向保持一定的具體性，但也要足夠精煉，讓下一個 Claude 有空間以極高工藝水準做出詮釋性的實作選擇。

哲學宣言必須引導下一個版本以**演算方式**表達想法，而非靜態圖像。美麗存在於過程之中，而非最終的畫面。

### 哲學宣言範例

**「Organic Turbulence」（有機湍流）**
哲學：受自然法則約束的混沌，從無序中湧現的秩序。
演算表達：由多層 Perlin 噪音驅動的流場。數千個粒子沿向量力場流動，其軌跡累積成有機的密度圖。多重噪音倍頻程創造出湍流區域與平靜地帶。色彩從速度與密度中湧現——快速粒子燃燒得明亮，緩慢的則褪入陰影。演算法持續運行直至達到平衡——一個精心調校的平衡點，每個參數都由計算美學大師經過無數次迭代反覆精煉而成。

**「Quantum Harmonics」（量子諧波）**
哲學：展現波狀干涉模式的離散實體。
演算表達：粒子在網格上初始化，各自攜帶隨正弦波演化的相位值。當粒子靠近時，它們的相位發生干涉——建設性干涉創造明亮節點，破壞性干涉形成虛空。簡單的諧波運動生成複雜的湧現曼陀羅。這是嘔心瀝血的頻率校準成果，每一個比例都經過仔細挑選，以產生共鳴之美。

**「Recursive Whispers」（遞迴低語）**
哲學：跨尺度的自相似性，有限空間中的無限深度。
演算表達：遞迴細分的分支結構。每個分支略帶隨機，但受黃金比例約束。L 系統或遞迴細分生成既有數學感又有機的樹狀形態。細微的噪音擾動打破完美對稱。線條粗細隨每次遞迴層級遞減。每個分支角度都是深度數學探索的產物。

**「Field Dynamics」（場域動態）**
哲學：看不見的力場透過其對物質的影響而得以顯現。
演算表達：由數學函式或噪音構建的向量場。粒子從邊緣誕生，沿場線流動，在到達平衡或邊界時消逝。多個場可以吸引、排斥或旋轉粒子。視覺化只顯示軌跡——看不見力場的幽靈般痕跡。一支由力平衡精心編排的計算舞蹈。

**「Stochastic Crystallization」（隨機結晶）**
哲學：隨機過程結晶成有序結構。
演算表達：隨機圓填充或 Voronoi 鑲嵌。從隨機點出發，透過弛豫演算法讓它們演化。各細胞相互推擠直至平衡。根據細胞大小、鄰居數量或距中心的距離上色。湧現的有機鑲嵌既感覺隨機又似乎必然。每個種子都產生獨特的結晶之美——大師級生成演算法的印記。

*以上為精煉版範例。實際的演算哲學應為 4-6 段有實質內容的段落。*

**核心演算法——表達哲學**：

**關鍵**：演算哲學應主導要建構的內容。

在透過程式碼表達哲學時，避免思考「應該使用哪種圖案？」，而是思考「如何透過程式碼表達這套哲學？」

- 隨時間累積或生長的元素

- 幾何關係與比率

- 嚴格邊界內的隨機變化
- 分岔與相變

**關鍵**：為了達到精通的境界，創作感覺像是由生成藝術大師經過無數次迭代才湧現的演算法。精心調校每個參數。確保每個圖案都有目的地湧現。這不是隨機噪音——這是透過深厚專業反覆精煉的**受控混沌**。

## 互動 Artifact 建立

### 關鍵：固定 vs 變動的區別

`templates/viewer.html` 檔案是地基。它包含所需的確切結構與樣式。

**固定（始終如實包含）：**

  - 上一個／下一個按鈕

  - 跳至種子輸入框 + 前往按鈕
- 側邊欄的操作區段：
  - 重新生成按鈕
  - 重設按鈕

**變動（為每件藝術品自訂）：**
- 整個 p5.js 演算法（setup/draw/類別）

  - 某些藝術品可能使用固定色彩
  - 某些藝術品可能是單色（不需要色彩控制項）
  - 根據藝術品的需求決定

**每件藝術品都應有獨特的參數與演算法！** 固定的部分提供一致的使用體驗——其他所有東西都表達獨特的願景。

- 數字參數的滑桿（粒子數量、噪音比例、速度等）

**4. 實作細節——建構側邊欄**

**需求**：

- 所有參數必須有 UI 控制項

- 加入「藝廊模式」並排顯示多個種子的縮圖
- 全部在同一個單一 artifact 中

這就像從同一塊版子印出一系列版畫——演算法是一致的，但每個種子都揭示其潛力的不同面向。互動的本質意味著使用者透過探索種子空間來發現自己的最愛。

---

## 創作過程

**使用者請求** → **演算哲學** → **實作**

每個請求都是獨一無二的。過程涉及：

1. **詮釋使用者的意圖**——追求的是什麼美學？
2. **建立演算哲學**（4-6 段），描述計算方式
3. **以程式碼實作**——建構表達此哲學的演算法
4. **設計適當的參數**——哪些應該是可調整的？
5. **建構對應的 UI 控制項**——那些參數的滑桿／輸入框

**常數**：
- Anthropic 品牌識別（色彩、字體、版面）
- 種子導航（始終存在）
- 自給自足的 HTML artifact

**其他一切皆是變動的**：
- 演算法本身
- 參數
- UI 控制項
- 視覺成果

為了取得最佳成果，信任創意並讓哲學引導實作。

## 資源

本 skill 包含實用的樣板與文件：

- **templates/viewer.html**：所有 HTML artifact 的**必用起點**。
  - 這是地基——包含確切的結構與 Anthropic 品牌識別
  - **保持不變**：版面結構、側邊欄組織、Anthropic 色彩／字體、種子控制項、操作按鈕
  - **替換**：p5.js 演算法、參數定義，以及參數區段中的 UI 控制項
  - 檔案中大量的注解精確標示出哪些保留、哪些替換

- **templates/generator_template.js**：p5.js 最佳實踐與程式碼結構原則的參考。
  - 展示如何組織參數、使用種子隨機性、建構類別
  - 不是圖案選單——用這些原則建構獨特的演算法
  - 演算法應內嵌在 HTML artifact 中（不要建立獨立的 .js 檔）

**關鍵提醒**：
- **樣板是起點**，而非靈感
- **演算法才是創造**獨特事物的地方
- 不要複製流場範例——建構哲學所要求的東西
- 但**務必**保留樣板中確切的 UI 結構與 Anthropic 品牌識別
