# Theme Factory Skill

本 skill 提供一組精心策劃的專業字體與色彩主題，每個主題都有仔細挑選的調色盤與字體搭配。選定主題後，即可套用到任何 artifact。

## 用途

若要為投影片或其他 artifact 套用一致、專業的樣式，請使用本 skill。每個主題包含：
- 附有十六進位色碼的協調調色盤
- 適用於標題與內文的互補字體搭配
- 適合不同情境與受眾的獨特視覺識別

## 使用說明

若要為投影片或其他 artifact 套用樣式：

1. **展示主題展示集**：顯示 `theme-showcase.pdf` 檔案，讓使用者直觀看到所有可用主題。不要做任何修改；直接展示以供檢視。
2. **詢問選擇**：詢問使用者要將哪個主題套用到投影片
3. **等待選定**：取得使用者對所選主題的明確確認
4. **套用主題**：一旦選定主題，將所選主題的色彩與字體套用到投影片／artifact

6. **Arctic Frost**（北極霜）——清爽透亮的冬日靈感主題
7. **Desert Rose**（沙漠玫瑰）——柔和精緻的沙塵色調
8. **Tech Innovation**（科技創新）——大膽現代的科技美學

## 主題詳情

每個主題都定義於 `themes/` 目錄中，包含完整規格：
- 附有十六進位色碼的協調調色盤
- 適用於標題與內文的互補字體搭配
- 適合不同情境與受眾的獨特視覺識別

## 套用流程

選定偏好的主題後：
1. 從 `themes/` 目錄讀取對應的主題檔案
2. 在整個投影片中一致地套用指定的色彩與字體
3. 確保適當的對比度與可讀性
4. 在所有投影片中維持主題的視覺識別

## 建立自訂主題

若現有主題均不適合某個 artifact，請建立自訂主題。根據所提供的輸入，生成一個類似上述主題的新主題。以描述字體與色彩組合代表意涵的類似名稱為主題命名。根據所提供的基本描述選擇適當的色彩與字體。生成主題後，展示供審閱與確認。確認後，依照上述方式套用主題。
